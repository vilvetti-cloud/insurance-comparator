# ТЕХНИЧЕСКОЕ ЗАДАНИЕ (ТЗ) НА ПОДГОТОВКУ ЭТАЛОННОГО АНАЛИТИЧЕСКОГО ОТЧЁТА ПО ДОКУМЕНТУ

**Универсальный шаблон для любой ИИ-системы**

---

## 0. Назначение документа

Настоящее ТЗ описывает **полный, самодостаточный процесс** подготовки аналитического отчёта по произвольному нормативному документу (правила страхования, договор, регламент, инструкция) на основе заданного перечня вопросов.

Цель — получить **отчёт, не требующий последующих правок**. Для этого ТЗ содержит:

- требования к входным данным;
- полный перечень типовых вопросов;
- правила анализа, исключающие типовые ошибки;
- обязательные блоки ответа по каждому параметру;
- структуру таблицы сравнения;
- пример заполнения;
- чек-листы самопроверки;
- формат вывода и шаблоны формулировок.

---

## 1. Входные данные

### 1.1. Обязательные

- **Файл документа** (PDF, DOCX, TXT или иной машиночитаемый формат).
- **Название документа** и, если применимо, редакция/дата вступления в силу.
- **Перечень вопросов** (см. раздел 3). Если перечень не задан — использовать типовой из раздела 3.

### 1.2. Опциональные

- Контекст: для какой цели готовится отчёт (юридическая проверка, сравнение, клиентская консультация).
- Ограничения: только текст документа, без внешних источников.

### 1.3. Требования к читаемости

Если PDF содержит технические артефакты (битые символы, наложения), ИИ обязан:

- игнорировать артефакты, не несущие смысла;
- не делать выводов на основе повреждённого текста;
- при необходимости указывать: «фрагмент текста нечитаем, вывод сделан по сохранившейся части».

## 2. Методология анализа

### 2.1. Принцип «только текст документа»

ИИ отвечает **исключительно на основе загруженного документа**. Внешние знания, другие редакции, судебная практика и общие представления о «стандартных» условиях не используются.

### 2.2. Различение уровней регулирования

Каждый ответ должен быть отнесён к одному из уровней:

| Уровень | Как обозначать |
|---|---|
| Прямо предусмотрено документом | «Предусмотрено» + пункт |
| Отнесено к другому документу (договору, полису, приложению) | «Определяется Договором» + указание, что именно |
| Прямо исключено | «Исключено» + пункт |
| Не упомянуто | «Прямо не упомянуто» + анализ ближайших по смыслу пунктов |
| Противоречие внутри документа | «Внутреннее противоречие» + оба пункта |

### 2.3. Работа с «молчащими» пунктами

Если вопрос не имеет прямого ответа:

1. Найти ближайшие по смыслу пункты (покрытие, исключение, ограничение).
2. Указать, что прямого ответа нет.
3. Не делать вывод «покрывается по умолчанию» и не делать вывод «исключено по умолчанию».
4. Дать корректную формулировку: «Прямо не упомянуто; решение зависит от обстоятельств и условий Договора».

### 2.4. Работа с отсылками

Если документ отсылает к Договору, закону или иному акту:

- указать это;
- не подменять содержание отсылки своими предположениями;
- отметить, что параметр определяется соответствующим документом.

### 2.5. Точность формулировок

- Использовать формулировки, близкие к тексту документа (особенно для порогов, сроков, лимитов).
- Различать «превышает», «равно или превышает», «не менее», «не более».
- Различать «страховая сумма», «страховая стоимость», «действительная стоимость».
- Различать «риск» и «страховой случай».

### 2.6. Ссылки на пункты

Каждое утверждение сопровождается ссылкой в формате:

- «п. X.Y»
- «п. X.Y.Z»
- «пп. X–Y»
- «подп. N п. X.Y»

## 4. Правила формирования ответов

### 4.1. Структура каждого ответа

Каждый ответ должен содержать:

1. **Прямой ответ** (одно предложение).
2. **Суть условия** (механизм).
3. **Числовые параметры** (сроки, проценты, лимиты).
4. **Условия применения**.
5. **Ограничения и исключения**.
6. **Отсылки к Договору**.
7. **Отсылки к закону**.
8. **Ссылки на пункты**.
9. **Уровень определённости**.

### 4.2. Шаблоны формулировок

**Прямое покрытие:**

> «Предусмотрено. [Условие]. Ограничения: [перечень]. Пункты: [ссылки].»

**Определяется Договором:**

> «Предусмотрено как механизм, конкретные параметры определяются Договором. [Что именно определяется]. Пункты: [ссылки].»

**Прямое исключение:**

> «Исключено. [Формулировка исключения]. Применяется, если иное не предусмотрено Договором. Пункты: [ссылки].»

**Не упомянуто:**

> «Прямо не упомянуто. Ближайшие по смыслу пункты: [ссылки]. Вывод: [корректная формулировка]. Решение зависит от обстоятельств и условий Договора.»

**Внутреннее противоречие:**

> «В документе есть расхождение: п. X говорит [А], п. Y говорит [Б]. Для корректного вывода необходимо [уточнение].»

### 4.3. Запрещённые формулировки

- «Скорее всего, покрывается».
- «Обычно так и бывает».
- «По стандартным правилам».
- «Как правило, суды...».
- Любые утверждения без ссылки на пункт.
- Подмена «не упомянуто» на «исключено» или «покрыто».

### 4.4. Точность по числам и срокам

- «Более 75%» ≠ «75% и более».
- «Не более 25%» ≠ «25%».
- «30 рабочих дней» ≠ «30 календарных дней».
- «С даты предоставления документов» ≠ «с даты обращения».
- «После получения результатов диагностики» ≠ «с момента обращения».

## 5. Обязательные блоки ответа (для каждого параметра)

Каждый ответ по каждому параметру **обязан** содержать следующие блоки. Если блок неприменим — писать «Не применимо» или «Не установлено», но **не пропускать**.

### 5.1. Блок 1. Прямой ответ

Одно предложение: «Предусмотрено» / «Не предусмотрено» / «Прямо не упомянуто» / «Определяется Договором» / «Исключено».

### 5.2. Блок 2. Суть условия

Развёрнутое описание механизма: что предусмотрено, как работает, в каких границах. 2–5 предложений, близко к тексту.

### 5.3. Блок 3. Числовые параметры

Все числа, сроки, проценты, лимиты, пороги. Если чисел нет — «Числовые параметры в документе не установлены».

### 5.4. Блок 4. Условия применения

При каких обстоятельствах параметр применяется. Если условий нет — «Применяется без дополнительных условий».

### 5.5. Блок 5. Ограничения и исключения

Что **не** покрывается, изъятия, оговорки, запреты. Перечень. Если ограничений нет — «Ограничения не установлены».

### 5.6. Блок 6. Отсылки к Договору

Что именно определяется Договором. Если отсылок нет — «Определяется только документом».

### 5.7. Блок 7. Отсылки к закону

Ссылки на законы, прямо упомянутые в документе. Если отсылок нет — «Отсылки к закону отсутствуют».

### 5.8. Блок 8. Ссылки на пункты документа

Точные ссылки. **Обязателен всегда.**

### 5.9. Блок 9. Уровень определённости

Одна из четырёх пометок:

- «Прямо предусмотрено»
- «Определяется Договором»
- «Прямо не упомянуто»
- «Прямо исключено»

### 5.10. Блок 10. Примечание (опционально)

Внутреннее противоречие, неоднозначность, спорная формулировка.

## 7. Пример заполнения по 10 параметрам

### 7.1. Франшиза

- **Прямой ответ:** Предусмотрена.
- **Суть условия:** Может быть безусловной, условной, условно-безусловной, прогрессивной безусловной. При безусловной — уменьшает возмещение на свой размер. При условной — не учитывается, если ущерб превышает франшизу.
- **Числовые параметры:** В документе не установлены; определяются Договором.
- **Условия применения:** По каждому страховому случаю, если иное не указано в Договоре.
- **Ограничения:** При отсутствии указания вида — считается безусловной.
- **Отсылки к Договору:** Размер, тип, порядок применения.
- **Отсылки к закону:** Нет.
- **Ссылки:** п. 1.6, 5.9–5.9.6, 12.7.
- **Уровень:** Предусмотрено, параметры — Договором.

### 7.2. Ремонт без справок

- **Прямой ответ:** Предусмотрен в установленных случаях.
- **Суть условия:** Можно обратиться без документов компетентных органов при повреждении остекления, одного наружного элемента категории B, наружных деталей иного ТС.
- **Числовые параметры:** 3% страховой суммы, но не более 45 000 ₽ — для иных ТС; один раз за срок договора/год — для одного элемента.
- **Условия применения:** Соблюдение перечня элементов; отсутствие кражи деталей; отказ от Европротокола по этому случаю.
- **Ограничения:** Скрытые повреждения не возмещаются; кража деталей не покрывается; обращение по Европротоколу лишает права на упрощённое урегулирование.
- **Отсылки к Договору:** Возможные дополнительные условия и лимиты.
- **Отсылки к закону:** Закон об ОСАГО (для Европротокола).
- **Ссылки:** п. 11.2.4, 11.2.4.1, 11.2.4.2, 11.2.4.3.
- **Уровень:** Предусмотрено.

### 7.3. GAP

- **Прямой ответ:** Предусмотрен.
- **Суть условия:** Дополнительный риск при утрате/уничтожении ТС. Выплата — после основной выплаты по «Ущербу»/«Хищению». Варианты: непогашенная задолженность, страховая стоимость по договору, рыночная стоимость.
- **Числовые параметры:** Не более 25% страховой суммы по «Ущербу»/«Хищению» на дату заключения Договора.
- **Условия применения:** Наличие действующего страхования по «Ущербу»/«Хищению» в РЕСО или аналогичного в другой организации.
- **Ограничения:** При отсутствии основного договора на дату случая GAP не является страховым риском.
- **Отсылки к Договору:** Вариант расчёта, конкретная сумма.
- **Отсылки к закону:** Нет.
- **Ссылки:** п. 4.1.4–4.1.4.1, 5.6, 6.7, 12.29.1–12.29.3.
- **Уровень:** Предусмотрено, параметры — Договором.

### 7.4. Порог тотала

- **Прямой ответ:** Предусмотрен.
- **Суть условия:** Если стоимость восстановительного ремонта превышает 75% страховой суммы по «Ущербу» — урегулирование на условиях «Полная гибель». Три варианта выплаты.
- **Числовые параметры:** Более 75%; 20% страховой суммы — для третьего варианта; 30/60 рабочих дней — сроки.
- **Условия применения:** Превышение порога; выбор варианта по соглашению сторон.
- **Ограничения:** Ровно 75% — недостаточно; вариант определяется письменным соглашением.
- **Отсылки к Договору:** Возможные иные критерии.
- **Отсылки к закону:** Нет.
- **Ссылки:** п. 5.5, 12.20–12.22, 12.26.
- **Уровень:** Предусмотрено.

### 7.5. Самовозгорание

- **Прямой ответ:** Включено в определение пожара.
- **Суть условия:** Пожар включает неконтролируемое горение или взрыв вследствие внешнего воздействия, самовозгорания ТС или замыкания проводки.
- **Числовые параметры:** Нет.
- **Условия применения:** Возникновение пожара.
- **Ограничения:** Замыкание проводки без пожара; неисправности систем, приведшие к пожару.
- **Отсылки к Договору:** Возможность иного.
- **Отсылки к закону:** Нет.
- **Ссылки:** п. 4.1.1, подп. 3; 4.1.1.1, подп. 5–6.
- **Уровень:** Предусмотрено с исключениями.

### 7.6. Терроризм

- **Прямой ответ:** Прямо не упомянут.
- **Суть условия:** Отдельного риска нет. Исключения сформулированы через причины (военные действия, волнения, забастовки).
- **Числовые параметры:** Нет.
- **Условия применения:** Зависит от обстоятельств события.
- **Ограничения:** Нельзя сделать вывод «покрыто» или «исключено» только по названию.

### 7.7. БПЛА / дроны

- **Прямой ответ:** Прямо не упомянуты.
- **Суть условия:** Могут подпадать под риск падения инородных предметов; автоматического покрытия нет.
- **Числовые параметры:** Нет.
- **Условия применения:** Оценка по обстоятельствам.

### 7.8. Эвакуатор

- **Прямой ответ:** Предусмотрен.
- **Суть условия:** Возмещение расходов на транспортировку при утрате возможности двигаться.
- **Числовые параметры:** 1% страховой суммы по «Ущербу»; один раз за страховой случай.
- **Условия применения:** Утрата возможности двигаться; документальное подтверждение.
- **Ограничения:** По общему правилу — не более 1%; при письменной рекомендации — полное возмещение.
- **Отсылки к Договору:** Иной порядок, количество, лимит.
- **Отсылки к закону:** Нет.
- **Ссылки:** п. 12.19.

### 7.9. Тип ремонта

- **Суть условия:** Денежная выплата или натуральное возмещение (ремонт на СТОА).
- **Числовые параметры:** Срок — до 60 рабочих дней; без учёта ожидания запчастей.
- **Условия применения:** Невозможность организации ремонта — денежная форма.

## 9. Формат вывода

### 9.1. Структура отчёта

1. **Заголовок**: название документа, редакция, дата.
2. **Источник**: файл, на основе которого сделан отчёт.
3. **Оговорка**: «Ответы основаны на тексте предоставленного документа. Условия, зависящие от Договора, отмечены отдельно».
4. **Основная часть**: ответы по разделам 3.1–3.16, раскрытые по блокам 5.1–5.9.
5. **Таблица сравнения** (по форме 6.1 или 6.2).
6. **Приложение**: чек-лист самопроверки.

### 9.2. Оформление

- Каждый пункт — отдельный блок.
- Внутри блока: ответ → условия → ограничения → ссылки.
- Таблицы — для перечней, сроков, лимитов.
- Единый стиль ссылок.

### 9.3. Язык

- Русский, юридически нейтральный.
- Без оценочных суждений.
- Без советов «как лучше».
- Без эмоциональных усилителей.

## 10. Ограничения

ИИ **не должен**:

- проверять документ на юридическую силу;
- сверять с другими редакциями;
- оценивать судебную перспективу;
- давать рекомендации по выбору условий страхования;
- добавлять нормы, которых нет в документе;
- использовать внешние источники, кроме тех, на которые прямо ссылается документ.

## 12. Приложение. Типовые ошибки, которых нужно избегать

| Ошибка | Как правильно |
|---|---|
| «Покрывается по умолчанию» | «Прямо не упомянуто; зависит от обстоятельств и Договора» |
| «Исключено по умолчанию» | «Прямо не упомянуто; прямого исключения нет» |
| «75% и более» | «Более 75%» (если в тексте «превышает») |
| «30 календарных дней» | «30 рабочих дней» (если в тексте «рабочих») |
| «С момента обращения» | «С даты предоставления всех документов» |
| «Страховая стоимость» вместо «страховая сумма» | Использовать термин из документа |
| «Риск» вместо «страховой случай» | Различать по определениям документа |
| «Официальный дилер» без упоминания в тексте | «В тексте не упоминается; выбор СТОА определяется Договором» |
| «Франшиза вычитается» без указания вида | «При безусловной — вычитается; при условной — не учитывается при превышении» |
| «GAP платится параллельно» | «GAP платится после основной выплаты» |
| Пустая ячейка в таблице | «Не установлено» / «Не применимо» / «Определяется Договором» |
