## Причина предыдущего сбоя автоматической обработки

- **Groq:** HTTP 413 — слишком большой запрос.
- **Gemini:** HTTP 503 UNAVAILABLE / overloaded.
- **OpenRouter:** ответ не прошёл проверку ожидаемой схемы/формата.

Это ошибки AI-обработки, а не вывод о том, что условия отсутствуют в PDF. Настоящее заполнение собрано по локальному корпусу документов и не требует нового запроса к AI-провайдерам.

## Ограничения и правила чтения отчёта

- В листе «Заполнение 110» есть ответ, страница, цитата, источник и статус доверия для каждого поля.
- Лист «Прямые находки» содержит 33 строки, которые были вручную исправлены/уточнены после прямого чтения конкретных пунктов PDF.
- «Не установлено» означает, что нужная норма не подтверждена просмотренным документом/фрагментом. Нельзя подменять это выводом «риск не покрывается».
- «Условный вывод» означает, что результат зависит от выбранной опции, полиса, причин события, исключений или связанных пунктов.
- Для финального пользовательского сравнения нужно сверять индивидуальный договор и не превращать условные формулировки в утверждение о гарантированном покрытии.
