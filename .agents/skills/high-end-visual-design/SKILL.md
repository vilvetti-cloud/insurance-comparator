# High-End Visual Design

Design as a polished product or agency experience rather than a generic template.

- Establish one coherent visual language per screen.
- Use typography as a primary structural element: clear scale, weight and rhythm.
- Prefer intentional spacing and hierarchy over excessive borders, shadows and decoration.
- Avoid default gray bordered cards, heavy drop shadows, random gradients and generic icon grids unless the existing product language requires them.
- Use contrast and surface changes to establish hierarchy instead of decorating every component.
- Give primary actions obvious visual priority.
- Treat responsive layouts as designed compositions, not desktop layouts squeezed into a phone.
- Use motion sparingly but deliberately for feedback, transitions and spatial continuity.
- Keep accessibility, readable contrast and keyboard focus visible.

Do not impose a new visual identity blindly. First inspect the existing product and preserve useful brand cues.
