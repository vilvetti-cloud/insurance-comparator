# Image To Code

When a visual reference is supplied:

1. Analyze hierarchy, spacing, typography, surfaces, imagery, component proportions and responsive behavior before coding.
2. Identify which visual details are essential and which can be implemented with existing project primitives.
3. Reuse the current framework and components where practical.
4. Match the reference through real layout and styling rather than embedding the screenshot as a substitute for the interface.
5. Check the result at the intended viewport and at mobile widths.
6. Do not create nested cards or decorative containers merely to imitate visual complexity.

If the reference is incomplete, preserve the project's established design language rather than inventing unrelated UI.
