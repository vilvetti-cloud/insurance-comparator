# Redesign Existing Projects

When redesigning an existing screen, do not start from scratch.

1. Scan the relevant files and identify framework, styling approach, components and state/data dependencies.
2. Diagnose weak hierarchy, repetitive cards, spacing problems, typography issues, poor responsive behavior, missing states and generic AI patterns.
3. Preserve working behavior and existing contracts.
4. Apply targeted visual improvements using the current stack.
5. Verify desktop, tablet and mobile behavior plus loading, empty, error, hover, focus and disabled states where relevant.

The visual goal is premium and intentional, but functionality always remains intact unless the user explicitly requests functional changes.
